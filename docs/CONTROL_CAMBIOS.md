## Criterio de control

Los avances registrados corresponden a documentación y planificación verificables en los commits enlazados. No se presentan como funcionalidades de software terminadas. La implementación, las pruebas, los diagramas gráficos finales y los estados actuales de Issues y Projects deben confirmarse con sus respectivas evidencias.

## Procedimiento para futuros cambios

1. Describir la necesidad o ajuste.
2. Registrar o actualizar el Issue correspondiente, cuando aplique.
3. Modificar los archivos relacionados.
4. Revisar la coherencia del cambio.
5. Guardar un commit con un mensaje claro.
6. Actualizar este registro cuando exista un avance significativo y verificable.
