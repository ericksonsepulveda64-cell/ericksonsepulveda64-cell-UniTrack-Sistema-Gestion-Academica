# Nota técnica de versión 0.1

## Tipo de versión

Línea base documental académica.

## Alcance

Esta versión reúne una descripción inicial del proyecto, requisitos, arquitectura propuesta, documentación del modelado UML, seguimiento de tareas y pautas de control de cambios.

## Contenido documental

- README principal del proyecto.
- Requisitos funcionales y no funcionales iniciales.
- Descripción de arquitectura por capas.
- Descripción de los modelos UML que deben mantenerse como evidencia gráfica.
- Referencias para seguimiento de tareas.
- Procedimiento sugerido para registrar cambios.

## Limitaciones

Esta versión no representa una aplicación terminada ni certifica que las funcionalidades descritas estén implementadas o probadas. Los modelos gráficos, los Issues y el tablero deben comprobarse y mantenerse sincronizados con el repositorio.

## Pendientes

1. Incorporar las exportaciones reales de los diagramas UML elaborados.
2. Verificar los requisitos y criterios de aceptación.
3. Confirmar los números, títulos y estados de los Issues en GitHub.
4. Revisar las columnas y tareas del tablero GitHub Projects.
5. Definir e iniciar la implementación de acuerdo con las prioridades académicas.
6. Añadir pruebas verificables conforme se desarrollen los módulos.

## Próximo paso

Validar la documentación y las evidencias existentes; después, priorizar una funcionalidad, asociarla a un Issue y mantener el vínculo entre implementación, commit y prueba.
