# Seguimiento del proyecto UniTrack

## 1. Propósito

Este documento resume las áreas de trabajo identificadas durante la planificación académica. Los estados definitivos de las tareas deben coincidir con el tablero actual de GitHub Projects y con sus Issues asociados.

## 2. Áreas de trabajo

- Requisitos e historias de usuario.
- Diseño de interfaz para consultas académicas.
- Diseño y configuración de la base de datos.
- Autenticación y roles.
- Consulta de asignaturas inscritas.
- Registro y consulta de calificaciones.
- Consulta de horario académico.
- Revisión de modelos y documentación.

## 4. Uso de GitHub Projects

El tablero Kanban debe mostrar las tareas en las columnas acordadas para la asignatura, por ejemplo: Backlog, Por hacer, En progreso, En revisión y Finalizado. Utilice los nombres reales del tablero y mueva una tarea solo cuando el trabajo correspondiente haya cambiado de estado.
